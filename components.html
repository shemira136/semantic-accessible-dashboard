Semantic HTML5

Semantic HTML describes the meaning and purpose of content rather than just its appearance.

Header

Introduces a page or a section.

Navigation

The nav element identifies a major group of navigation links.

Main content

The main element identifies the primary content of the page.

Section and Article

Sections group related content. Articles represent self-contained content.

Aside

Provides related content, such as a sidebar.

Footer

Provides information about a page or section.

Page Landmarks

Landmarks help assistive technology users navigate between major regions of a web page.

  • Banner: site header
  • Navigation: primary navigation
  • Main: primary page content
  • Complementary: sidebar
  • Content information: page footer

Accessibility Principles

Keyboard accessibility

Interactive controls should be usable with a keyboard.

Visible focus

Users should be able to identify the focused control.

Accessible names

Buttons and form controls should have meaningful accessible names.
