Accessibility Information

This dialog demonstrates the native HTML dialog element, which provides built-in keyboard support and modal behavior.

Accessible dialogs should have a clear title, a predictable closing mechanism, and appropriate keyboard focus management.

Modal Accessibility Guidelines

Keyboard Access

Users should be able to operate the dialog without using a mouse.

Dialog Name

The dialog has an accessible name through its heading.

Focus Management

When the dialog closes, focus should return to the button that opened it.
